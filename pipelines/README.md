# pipelines

Vazio de propósito. Esta pasta existe na estrutura do template para
processos executados em mecanismo de workflow (Orange) ou de notebook
(Jupyter, R), e o nosso pipeline não usa nenhum dos dois: ele roda como
módulo Python.

O ponto de entrada é `src/kg_extraction/run_pipeline.py`, com as
instruções de instalação e execução em [`src/README.md`](../src/README.md).
